# DSA Roadmap

This roadmap is designed for someone who understands programming basics but does not yet visualize data structures naturally.

Do not measure progress by number of videos watched. Measure it by how many patterns you can trace and implement without help.

## Phase 1 - Foundation Loops And Memory

Goal: become comfortable moving through data and remembering state.

Topics:

1. Arrays and strings
2. Hash maps and sets
3. Two pointers
4. Sliding window

Expected practice:

- 40 to 60 beginner problems
- 15 to 25 medium problems
- No hard problems yet

## Phase 2 - Linear Data Structures

Goal: understand data that grows, shrinks, or points to other data.

Topics:

1. Stack
2. Queue
3. Linked list
4. Recursion basics

Expected practice:

- 30 to 40 beginner problems
- 15 to 20 medium problems

## Phase 3 - Trees

Goal: visualize parent, child, depth, traversal, and recursive thinking.

Topics:

1. Binary tree traversal
2. Binary search tree
3. Tree height and depth
4. Path problems

Expected practice:

- 25 to 35 beginner problems
- 15 to 20 medium problems

## Phase 4 - Search And Priority

Goal: learn controlled search instead of checking everything blindly.

Topics:

1. Binary search
2. Heap / priority queue
3. Sorting patterns

Expected practice:

- 20 to 30 beginner problems
- 15 to 20 medium problems

## Phase 5 - Graphs

Goal: understand connected things.

Topics:

1. Graph representation
2. Breadth-first search
3. Depth-first search
4. Grid problems

Expected practice:

- 25 to 35 beginner problems
- 20 to 25 medium problems

## Phase 6 - Dynamic Programming Basics

Goal: recognize repeated subproblems without panic.

Topics:

1. Recursion tree
2. Memoization
3. Bottom-up tabulation
4. 1D DP patterns

Expected practice:

- 20 beginner problems
- 15 medium problems

## Revision System

For every topic, revise after:

- 1 day
- 3 days
- 7 days
- 14 days

During revision, do not reread everything. Instead:

1. Redraw one visual.
2. Re-solve two old exercises.
3. Explain the pattern in `progress.md`.

## When To Move On

Move to the next topic only when:

1. You can solve at least 70 percent of beginner exercises for the topic.
2. You can explain the main pattern without reading notes.
3. You can solve 2 or 3 medium exercises with hints.

This is not a race. DSA becomes easier when the same mental pictures repeat enough times.
