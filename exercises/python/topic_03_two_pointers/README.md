# Topic 03 - Two Pointers Exercises

Read `lessons/03_two_pointers.md` first.

Implement one function at a time in `two_pointers.py`, then run:

```powershell
python -m unittest discover -s exercises/python
```

Unimplemented functions are skipped, so later exercises will not create a wall
of errors.

1. `reverse_values`
2. `is_palindrome`

Intermediate:

7. `sorted_squares`

Medium:
