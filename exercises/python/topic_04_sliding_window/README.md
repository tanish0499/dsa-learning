# Topic 04 - Sliding Window Exercises

Read `lessons/04_sliding_window.md` first.

Implement one function at a time in `sliding_window.py`, then run:

```powershell
python -m unittest discover -s exercises/python
```

Unimplemented functions are skipped.

## Order

Fixed-window beginner exercises:

1. `fixed_window_sums`
2. `max_sum_fixed_window`
3. `count_windows_at_least`
4. `max_vowels_in_window`
5. `has_nearby_duplicate`

Variable-window exercises:

6. `smallest_subarray_at_least`
7. `longest_subarray_at_most`
8. `longest_unique_substring`

Medium exercises:

9. `find_anagram_indices`
10. `longest_repeating_after_replacements`

For now, implement only `fixed_window_sums` and `max_sum_fixed_window`.
