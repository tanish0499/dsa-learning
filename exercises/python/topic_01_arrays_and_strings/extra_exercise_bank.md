# Extra Exercise Bank - Arrays And Strings

Use these after the tested functions in `arrays_strings.py`.

Do not solve all of them in one sitting. Pick 3 to 5 per session.

## Beginner

1. Return the first element of a list.
2. Return the last element of a list.
3. Count how many numbers are greater than 10.
4. Count how many strings have length greater than 3.
5. Return the sum of only positive numbers.
6. Return the sum of only negative numbers.
7. Return a new list with every number increased by 1.
8. Return a new list with only odd numbers.
9. Return `True` if all numbers are positive.
10. Return `True` if any number is negative.
11. Count uppercase letters in a string.
12. Count vowels in a string.
13. Replace every space in a string with `_`.
14. Return a string without vowels.
15. Return the index of the first occurrence of a target value.
16. Return `-1` if the target value is not found.
17. Return the smallest number in a list.
18. Count how many times the maximum number appears.
19. Build a list of squares.
20. Return the total length of all words in a list.

## Medium

1. Return the second smallest distinct number.
2. Remove duplicates while keeping original order.
3. Rotate a list right by one position.
4. Rotate a list left by one position.
5. Return the longest word in a list.
6. Return the most frequent character in a string.
7. Check whether two strings are anagrams.
8. Merge two already sorted lists.
9. Find the first non-repeating character.
10. Return the running sum of a list.
11. Find the maximum difference where the larger number appears after the smaller number.
12. Return all pairs that sum to a target using simple nested loops.
13. Convert `"a3b2c1"` into `"aaabbc"`.
14. Check whether a list is sorted in ascending order.
15. Find the longest streak of the same number.

1. Two sum using a hash map.

3. Minimum size subarray sum.
4. Product of array except self.
5. Three sum.
6. Container with most water.
7. Longest repeating character replacement.
8. Group anagrams.
9. Find all anagrams in a string.
10. Maximum subarray.
