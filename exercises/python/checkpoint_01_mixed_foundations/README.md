# Checkpoint 01 - Mixed Foundations

These exercises mix arrays, strings, sets, dictionaries, two pointers, and
sliding windows. The prompt will not tell you which technique to use.

Before coding each function, write three short lines on paper:

```text
State I need to remember:
Condition that makes the current state valid or invalid:
Reason the chosen structure fits:
```

Run all tests with:

```powershell
python -m unittest discover -s exercises/python
```

Unimplemented functions are skipped.

stuck for 25 minutes, ask for one small hint and record what clue unlocked it.
